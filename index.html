Instructions:

  • Goal: Get to 2048!
  • How to play:
    • Use the arrow keys or swipe the screen to move the blocks in that direction.
    • When two blocks of the same value collide, they combine into a larger block.
    • You gain points for each block you create, with more for larger blocks.
    • After each move, a new block is spawned.
    • If there are no more moves left, it's game over!
